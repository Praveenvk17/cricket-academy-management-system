# Cricket Academy Management System

Cricket Academy Management System is a Java-based web application developed using Java, JSP, Servlets, MySQL and Maven.

## Technologies Used

- Java
- JSP
- Servlets
- MySQL
- Maven
- HTML
- CSS
- JavaScript

## Project Description

This system helps manage cricket academy activities, student details, coach details and other academy-related information through a web application.

## Features

- Student management
- Coach management
- Academy management
- Database connectivity
- Email notification
- Web-based user interface

## How to Run

1. Download the project ZIP file.
2. Extract the ZIP file.
3. Import the Maven project into Eclipse.
4. Configure the MySQL database.
5. Update the database and email configuration.
6. Run the project using a compatible server such as Apache Tomcat.
